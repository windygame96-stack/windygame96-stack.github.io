# 给另一半看的相处说明卡

日期：2026-11-09；基线 `1a4d271`；报告版本 `rf-card-1.0`；答题契约仍为 `rf-2.0`。

目标：伴侣收到一张图片，就知道怎样联系、安慰、处理分歧，以及哪些边界需要先询问。

## 范围与规则

- 不改十二道题、选项含义、点选流程、有效回答门槛或保存规则。完整旧答案可直接生成新版报告。
- 联系方式四项 × 压力支持四项，确定性映射为十六个相处昵称；没有总分、概率或人格诊断。缺一个锚点就仅使用另一个，三个核心话题都未回答时使用“待补全的相处说明卡”，不强行赋予称号。
- 其余建议逐项映射真实选择。网页保留十二题的可展开依据，下载摘要突出日常关心、烦心和争执、应避免的做法、三条生活约定、隐私与亲近，以及一句示例回应。
- 用户明确选择的重要性只影响生活约定的摘要顺序，不改变答案含义。未回答的部分不解释。原始备注、旧版追问和未经提供的经历不进入卡片或导出对象。
- 双人模式分别生成 A、B 两张卡，可切换、分别下载；双方共同回答至少六题才补充双人差异。修改 A 后不重启或覆盖 B。
- PNG 与网页使用同一份模型；固定宽 1080px、按真实字体测量动态换行和高度，避免中文标点单独换行。超出画布上限或生成失败时给出明确提示，保留打印及展开图片保存入口。
- 所有图片在当前浏览器本地生成；不上传、不发送给任何人、不添加第三方服务或身份填写。
